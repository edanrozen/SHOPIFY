# The Horizon icons these replace

The four files beside this note are Shopify Horizon's own header icons, kept
byte for byte as they shipped. The theme's `assets/icon-*.svg` are overwritten
with the TinyBloom drawings in `variants/showcase/icon-*.svg`, and overwriting
a core theme asset is only safe if the original is somewhere.

To put Horizon's back, copy the file from here over the one in `assets/`.
